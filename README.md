Flutter Weather App

Hey there! This is a simple weather app I built with Flutter. It's a bit different - instead of typing in your city, you just enter your student index number and it figures out the weather for you.

What It Does

- Enter your student index and get weather info
- See current weather conditions
- Check your search history
- Works offline too (saves your last searches)

Quick Start

Make sure you have Flutter installed, then:

bash
git clone https://github.com/dilusha-ola/flutter-weather-app.git
cd flutter-weather-app
flutter pub get
flutter run

How to Use

Pretty straightforward:
1. Open the app and type in your student index
2. Hit the "Fetch" button
3. Check out the weather on your dashboard
4. Browse through different sections using the bottom menu

That's it! Your searches get saved automatically so you can look back at them later.

Built With

- Flutter
- A weather API
- Some helpful packages for caching and formatting
